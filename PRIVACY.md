# Privacy Policy

This Privacy Policy explains how the Deployment Tool handles information collected through the software and related project resources.

## 1. Information We Collect

The tool may collect or process the following information when used:

- Deployment configuration data
- File paths and project-related metadata
- Tool usage information such as feature access and error logs
- Device or environment information necessary to diagnose application issues
- User-provided contact details if supplied through project support channels

## 2. How We Use Information

We use information to:

- operate and improve the Deployment Tool
- troubleshoot software errors and performance problems
- support deployment workflows and project automation
- maintain security and integrity of the application
- communicate with users when support or updates are required

## 3. Data Storage and Security

We take reasonable measures to protect information from unauthorized access, alteration, disclosure, or destruction. However, no internet-connected system can guarantee complete security.

## 4. Sharing of Information

We do not sell personal information.

Information may be shared only when:

- required to provide core functionality of the tool
- necessary for technical support, hosting, or maintenance
- required by law, regulation, or legal process
- needed to protect the rights, property, or safety of the project, users, or others

## 5. Third-Party Services

If this project uses third-party services such as hosting, telemetry, or cloud infrastructure, those services may process data under their own privacy policies. Users should review those policies where applicable.

## 6. Retention

We retain information only as long as necessary to fulfill the purposes described in this policy, comply with legal obligations, resolve disputes, or enforce agreements.

## 7. Your Choices

You may choose not to provide certain information, but this may limit the functionality of the Deployment Tool. If you have any questions about data handling, please contact the project maintainer.

## 8. Changes to This Policy

This Privacy Policy may be updated from time to time. Any changes will be reflected in this document and should be reviewed periodically.

## 9. Contact

If you have any questions or concerns about this Privacy Policy, please contact the repository owner or project maintainer through the GitHub project contact details.
